# Scripts

Planned utilities:

- `install.sh`: inspect, back up and activate a selected configuration.
- `backup.sh`: create a timestamped backup.
- `restore.sh`: restore a selected backup.
- `check-dependencies.sh`: report required and optional tools.
- `validate.sh`: run available static validation.

No installer is provided yet. Scripts must be safe by default, explain their actions and never silently overwrite user files.
